🍒 Cherry máy này

Bộ giải Cherry chạy bằng CPU của máy này. Dữ liệu trường vẫn lưu trên tkbcherry.com.

Trạng thái

Đang chạy

Giải thử bằng file .cherry

Chọn file xuất từ nút File .cherry trong app. File chỉ đọc trong máy này, không gửi đi đâu.

Chỉ sốTrướcSau

Kiểm tra tự bật lại

  1. Mở Task Manager, kết thúc tiến trình pythonw.exe của Cherry (hoặc khởi động lại máy).
  2. Bấm Win + R, gõ cherry-local://start, Enter — bộ giải bật lại ngầm, không có cửa sổ.
  3. Tải lại trang này: trạng thái phải là Đang chạy.

Gỡ cài đặt: Settings → Apps → Installed apps → Cherry máy này → Uninstall.
